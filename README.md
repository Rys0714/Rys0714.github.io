# Reading Fog v0.3b.1

日语短片段与雾中阅读互动原型。玩家用鼠标模拟视线，在雾中寻找文字；按 `SPACE` 确认片段，留下三个阅读单位后，把鼠标停在中央时钟上并长按 `SPACE`，形成自己的车站场景。

## 操作

- 移动鼠标：探索雾中的文字
- `SPACE` / 点击：确认当前文字
- `Esc` / 右键：撤销上一次确认
- 三个蓝点出现后：把鼠标停在中央时钟上，长按 `SPACE`
- `R`：结局后重新开始

## 在线发布

本项目已经整理为单文件 `index.html`，无需安装依赖。

在 GitHub 仓库中打开 `Settings` → `Pages`，选择 `Deploy from a branch`、`main`、`/(root)` 后保存即可。
